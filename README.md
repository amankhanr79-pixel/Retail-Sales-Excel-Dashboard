# 📊 Retail Sales Performance Dashboard (Excel)

## Project Overview
This project is an interactive Excel dashboard built to analyze retail sales performance across multiple cities and sales executives. It helps users monitor KPIs, compare sales performance, and track target achievement using dynamic visualizations.

## Business Problem
Sales managers need a quick and interactive way to monitor sales performance instead of manually analyzing large datasets.

## Features
- Interactive City-wise Slicer
- Sales Executive Performance Analysis
- Total Sales Dashboard
- Target Hit Percentage
- Away From Target Percentage
- Pivot Tables & Pivot Charts
- KPI Dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- VBA
- Conditional Formatting
